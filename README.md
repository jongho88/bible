# StepBible

흐름으로 읽는 개역한글 성경 웹앱이에요. 큰 그림 카드, 365일 시대순 읽기표, 66권 해설, 검색·마크·메모, 읽어주기 기능이 있어요.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| index.html | 앱 화면 전체 |
| bible.json | 개역한글 본문 (31,101절) |
| sw.js | 인터넷 없이도 열리게 해 주는 파일 |
| manifest.webmanifest | 홈 화면에 앱처럼 설치하게 해 주는 파일 |
| sb3-icon-192.png, sb3-icon-512.png, sb3-touch-180.png | 홈 화면 아이콘 |
| thumb.png | 링크 공유 시 미리보기 그림 |

파일 이름과 위치를 바꾸지 말고, 모두 같은 폴더에 그대로 올려 주세요.

## GitHub Pages로 올리기 (무료)

1. github.com 에 로그인하고 오른쪽 위 **+** → **New repository**를 눌러요.
2. Repository name에 `bible`처럼 영어 이름을 쓰고, **Public**을 고른 뒤 **Create repository**를 눌러요.
3. 다음 화면에서 **uploading an existing file** 링크를 눌러요.
4. 압축을 푼 폴더 안의 파일 9개를 모두 끌어다 놓고, 아래 **Commit changes**를 눌러요.
5. 저장소의 **Settings** → 왼쪽 **Pages**로 가서, Branch를 **main**, 폴더를 **/(root)** 로 고르고 **Save**를 눌러요.
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요. 예: `https://아이디.github.io/bible/`

## 휴대폰 홈 화면에 설치하기

- 아이폰(사파리): 주소를 열고 아래 **공유 버튼** → **홈 화면에 추가**
- 안드로이드(크롬): 주소를 열고 오른쪽 위 **⋮** → **홈 화면에 추가** 또는 **앱 설치**

한 번 열어 두면 그다음부터는 인터넷이 없어도 읽을 수 있어요.

## 알아 두실 점

- 마크·메모·읽은 날은 각자의 기기(브라우저)에만 저장돼요. 다른 기기로 옮기려면 앱의 **내 기록 → 백업**에서 복사하고 붙여 넣으세요.
- 읽어주기는 기기에 들어 있는 한국어 음성을 써요.
- 카카오톡 등에서 링크 미리보기 그림이 안 나오면, index.html의 `og:image` 줄에 있는 `thumb.png`를 전체 주소로 바꿔 주세요. 예: `https://아이디.github.io/bible/thumb.png`
- 앱 내용을 고쳐서 다시 올릴 때는 sw.js 맨 위의 `bible-v1`을 `bible-v2`처럼 숫자를 올려 주세요. 그래야 이미 설치한 사람들 기기에도 새 내용이 반영돼요.
